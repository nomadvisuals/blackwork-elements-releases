# Security

Please report security problems in Blackwork Elements by email to **hello@blackwork.pro**, with "Security" in the subject. Don't open a public issue for them.

Include the app version (Blackwork Elements → About), your macOS version and the steps to reproduce. We'll confirm that we've received your report and keep you updated while we look into it.

Only download Blackwork Elements from this repository's [Releases](https://github.com/nomadvisuals/blackwork-elements-releases/releases) page, and check the file against `SHA256SUMS.txt` (see the README).
